# samastrift01: animated astral veils

The effect selects the exact model `samastrift01` (optional `.mod`, ASCII case-insensitive) and only `empty_veillow`, `empty_veilcrown`, `empty_veilcross`, `empty_veilwake`. Stone and core geometry, textures and transforms are unchanged. There is no gameplay effect, new resource archive or setting.

`astral_rift.h` adds four immutable generated parts to the completed appearance. Each contains eight crossed, double-sided clumps sampled from that veil's authored UV edge (32 clumps, 256 triangles total). They share the veil's skeleton node, texture and material, inherit its hidden state and disappear with the same appearance lifecycle. Completed host appearance updates resolve these generated parts through the original skeleton node, not a nonexistent host figure. Generation is idempotent, including initially hidden veils.

`NativePreparedPartValues::astral` and the matching GPU/HLSL layout carry normalized logical time, effect kind and veil phase. Logical time is `GetPreciseTime()` in 55 ms quants; the period is six game seconds. No wall-clock accumulator, particle allocations or retained game-object pointers are used. Pausing the logical clock pauses the effect; loading a different clock directly reconstructs it.

The world vertex shader adds a small local wave to veil positions (maximum Z amplitude 0.28), leaving their endpoints fixed. Clumps move along a local tangent and outward/upward, then fade out before wrapping. Displacements are transformed by the same node matrix as the model, so placement, rotation and scale apply to the effect.

The pixel shader scrolls two texture samples within U `[0.0166015625, 0.4833984375]`, preserving the original veil V coordinate. Complementary sine-squared weights remove the visible wrap seam without reading another atlas quadrant. Clumps use V `[0.5166015625, 0.9833984375]`, a soft spatial mask and lifetime alpha. Source gradients are retained across the wrap. Both regular and Low material shader paths use the effect.

These transparent parts preserve draw order, use no depth writes and cast no shadows. Stones retain their existing shadow policy. The model leaves the persistent static-color set; effect parts do not use static mesh LOD simplification. Conservative object/part envelopes include the maximum displacement (0.5 for waves, 7 for clumps). Geometry and world-pose caches retain the resting data; color deformation runs after cached world vertices are read.

Validation command: `tools/check-astral-rift.ps1 -OutputDirectory <task>/check`. Covers exact model/part selection, unrelated-model exclusion, preservation of source geometry and stone shadow policy, generated indices/finite coordinates, stable count/idempotence, initially-hidden inheritance, and atlas coordinate bounds. Full x64 build compiles the production shaders; this does not establish in-game visual acceptance. Review after an explicitly authorized installation: existing placed samastrift01 from all sides, pause/resume, camera/frustum edge, rotated/scaled placements, hide/show, map transition, alpha overlap with rocks, and multiple instances. No installation is part of this change.
