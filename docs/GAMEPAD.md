# Геймпад Xbox / XInput

Контроллер определяется автоматически, включая подключение после запуска.
Используется один контроллер: первый обнаруженный слот XInput. После его
отключения игра ищет доступный контроллер снова. DirectInput не поддерживается.

| Управление | Действие |
|---|---|
| Левый стик | Курсор; скорость зависит от отклонения стика |
| LB + левый стик | Точное перемещение курсора |
| A | Левая кнопка мыши; удержание — перетаскивание; два нажатия — двойной клик |
| B | Правая кнопка мыши; B + левый стик — штатное управление камерой правой кнопкой |
| Правый стик | Перемещение камеры в миссии, как клавишами направлений |
| RT / LT | Колесо мыши вверх / вниз: масштаб камеры или прокрутка интерфейса |
| X | Пауза в миссии |
| Y | Мини-карта в миссии |
| View / Back | Задания в миссии |
| Menu / Start | Escape: меню / назад |
| Крестовина: влево / вверх / вправо | Выбор героя 1 / 2 / 3 |
| Крестовина: вниз | Выбрать всех |
| Нажать левый стик | Штатная команда слежения камеры |
| Нажать правый стик | Штатная команда нормального положения камеры |
| RB | Shift для сочетаний с кликами |

Команды миссии используют текущие клавиатурные назначения игры. Если команда
полностью отвязана от клавиатуры, соответствующая кнопка геймпада её не вызывает.
В меню, инвентаре и диалогах используется курсор и клики. Экранная клавиатура,
вибрация, отдельное переназначение кнопок геймпада и прямое движение героя
в эту реализацию не входят.

Ввод действует только в активном окне игры. При подключении, возвращении
фокуса или смене экрана отпустите кнопки, стики и триггеры в нейтральное положение.
Это предотвращает случайные клики на новом экране. При отключении контроллера
зажатый ввод отменяется через штатный сброс интерфейса.

## Проверка на физическом контроллере

Автоматическая проверка `tools/check-gamepad.cpp` проверяет математику стиков
и объединение состояний кнопок двух устройств. Она не заменяет игровой прогон.

- Открыть меню, выбрать пункт A, вернуться Start; проверить курсор и точность LB.
- В миссии: выбор героев, движение кликом, взаимодействие и атака, X, Y, View.
- Камера: правый стик, B + левый стик, RT/LT; отсутствие дрейфа в покое.
- Инвентарь/лагерь: перетаскивание A, двойной клик, прокрутка и закрытие окна.
- Отключить контроллер при удержании A, B и направления камеры; проверить остановку.
- Потерять фокус с зажатой кнопкой, вернуться, отпустить управление и продолжить.
- Подключить контроллер после запуска; проверить клавиатуру/мышь до и после.
- Удерживать одну кнопку мышью и геймпадом, отпустить по очереди: отпускание
  должно произойти только после последнего устройства.
