# Геймпад Xbox / XInput

Контроллер определяется автоматически, включая подключение после запуска.
Используется первый обнаруженный слот XInput; после его отключения поиск повторяется.

| Управление | Действие |
|---|---|
| Левый стик | Курсор |
| A | Левый клик; удержание — перетаскивание; два нажатия — двойной клик |
| B | Правый клик; B + левый стик — штатное управление камерой правой кнопкой |
| Правый стик | Перемещение камеры в миссии |
| LT / RT | Колесо вниз / вверх: масштаб или прокрутка |
| X | Пауза в миссии |
| Y | Мини-карта в миссии |
| View / Back | Задания в миссии |
| Menu / Start | Escape: меню / назад |
| Крестовина вверх / вниз | Поза на одну ступень выше / ниже |
| Крестовина влево, коротко | Следующий живой герой |
| Крестовина влево, долго | Следующее оружие среди четырёх слотов |
| Крестовина вправо, коротко | Следующий быстрый предмет среди четырёх слотов |
| Крестовина вправо, долго | Предыдущий живой герой |
| LB удерживать | Shift |
| RB удерживать | Alt |
| LB + повторные нажатия LT | Выбор по кругу иконки левой панели; отпустить LB — активировать |
| RB + повторные нажатия RT | Выбор по кругу иконки правой панели; отпустить RB — активировать |
| Одновременное нажатие L3 + R3 | Переключение изометрии, как Shift + N |

Порядок поз: лежать → присесть → стоять → бежать. На крайних ступенях переход
останавливается; у нескольких выбранных героев поза меняется на одну ступень
для каждого. Долгое нажатие — от 450 мс, срабатывает один раз за удержание.
Короткое срабатывает при отпускании; после долгого короткое не выполняется.
Пустые оружейные и предметные слоты пропускаются. Быстрый предмет выбирается,
а не применяется автоматически к герою. Одиночные нажатия L3 и R3 не вызывают
прежние команды камеры. LB больше не замедляет курсор.

Выбираемая иконка подсвечивается штатным увеличением и освещением. До отпускания
бампера её команда не выполняется. Первое нажатие триггера выбирает следующую
иконку после текущей, а при отсутствии выбора — первую. Удержание триггера не
повторяет переключение. При выборе триггер не меняет масштаб; после отпускания
бампера он снова управляет масштабом только после полного отпускания триггера.
Смена героя/состава панели, экрана, потеря фокуса и ручной клик отменяют выбор.

Поза, циклический выбор и панели используют штатные команды игры напрямую,
независимо от клавиатурных назначений. Пауза, мини-карта, задания и направления
камеры используют текущие назначения клавиатуры. В меню, инвентаре и диалогах —
курсор и клики. Shift/Alt доступны и интерфейсу лагеря.

Ввод действует только в активном окне игры. После подключения, возвращения
фокуса или смены экрана отпустите кнопки, стики и триггеры в нейтральное положение.
Отключение отменяет удержания и незавершённый выбор, без активации иконки.
DirectInput, вибрация, экранная клавиатура и прямое движение героя не реализованы.

## Пропуск видеороликов

В разрешённом к пропуску ролике нажмите любую цифровую кнопку (например A, B
или Start). Стики и триггеры сами ролик не пропускают. Уже зажатую при начале
ролика кнопку сначала отпустите. Нажатие не переносится в следующий ролик или меню.
Непропускаемые участки сохраняют штатные ограничения игры.

## Проверка владельцем в игре

Автоматический тест `tools/check-gamepad.cpp` проверяет переходы нажатий,
выбор/отмену, пороги триггеров, модификаторы, позы/циклы и пропуск видео.
Он не заменяет физический игровой прогон.

- Проверить четыре позы в обе стороны, крайние ступени и смешанный выбор героев.
- Проверить короткие и долгие нажатия влево/вправо, без двойного действия.
- Проверить LB/Shift и RB/Alt: удержание, отпускание, сочетание с клавиатурой и лагерь.
- Перебрать обе панели, проверить подсветку и активацию только при отпускании бампера.
- Проверить меню тактики и все доступные слоты правой панели, включая боевые навыки.
- Проверить отмену выбора при потере фокуса, смене героя и отключении контроллера.
- Проверить, что триггер выбора не меняет масштаб, а после отпускания снова меняет.
- Проверить L3 + R3: одно переключение за нажатие, без отдельных команд L3/R3.
- Проверить меню, клики, перетаскивание, двойной клик, паузу и камеру.
- Пропустить вступительный ролик свежим нажатием, затем проверить отсутствие клика в меню.
