# Кандидаты регистрации поселений

`zone1-poselok.candidate.json` — полный кандидат `settlements.json` для этапа 3
X64PEACE01. Он не загружается автоматически из исходников и не установлен в мод.
У записи 1 пока нет поля `mob`: NPC и скрипты Посёлка добавляются позднее отдельным
модулем. Границы взяты по текущим стенам модернизированной владельцем Zone1;
существующие объекты карты не создаются и не переносятся.

Перед будущей игровой приёмкой нужны разрешённый комплект и явная активация
реестра в корне мода. Переход у ворот 1725 (выход 2 в `bz1g`) тогда станет
локальным. Без реестра установленное поведение карты сохраняется.

Разговоры, торговля, первая сцена Старосты и завершение сюжетных цепочек пока
не перенесены. Использовать для новой игры: кандидат движка сохраняет схему v5.
Высота области, проход ворот и тревога требуют игровой приёмки владельцем.
