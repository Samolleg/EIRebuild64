# Сборка задания EIRebuild64 (Release x64)

Из `tasks/<ID>/wt` выполните одну команду в проектном PowerShell 7.6.10:

```powershell
& ./tools/build-task.ps1
```

NavBake выпускается отдельно. Обычная сборка решения пропускает проект запекателя. Упаковщик переносит принятые EIRebuild64NavBake.exe и соответствующий PDB из current, сверяя оба SHA-256. Это правило действует для изменений в любых игровых CPP, заголовках и проектах.

Для отдельного выпуска запекателя увеличьте целое число в `Navigation/NavBake.release`. В этом случае штатная сборка также собирает самостоятельный проект NavBake с текущими объектами движка. Номер входит в Git и в комплект, поэтому решение сохраняется при слиянии и приёмке. Ноль обозначает существующий выпуск до введения нумерации. Изменение формата Nav64 или импортёра, которое нужно доставить в запекатель, включайте в отдельный выпуск. Файлы карт сборка не запекает.

Нужны локальные Visual Studio Build Tools 2022 с v143, MFC, Windows SDK,
`deps/ffmpeg/9.0.2/x64`, `deps/dlss-sdk/v310.9.16`, пакеты `deps/nuget`.
Скрипт находит RULES.md выше рабочей копии. Загрузок и NuGet restore нет.
Исходники DirectXTex/TK, Recast и LuaJIT уже находятся в репозитории.
Подробности лицензий — THIRD_PARTY.md, сборки FFmpeg — tools/ffmpeg/README.md.

Скрипт изолирует TMP/TEMP и endpoint сервера PDB уникальным ID запуска,
очищает унаследованные CL/LINK flags, готовит зависимости, запускает MSBuild
с `/m` по числу логических процессоров, `/nr:false`, `/MP` и `/FS`.
`MSBUILDDISABLENODEREUSE=1` запрещает повторное использование узлов. Корневой
MSBuild запускается приостановленным и до старта помещается в отдельный Windows
Job Object: он учитывает точные процессы этого запуска, включая осиротевшие узлы.
После завершения MSBuild оставшиеся процессы этого job завершаются с ожиданием
опустошения job. Процессы других сборок в него не входят.
PDB компилятора лежит в IntDir проекта, линкера — в OutDir проекта.
Игра использует штатный stdafx PCH; рендер и генератор шейдеров — отдельный
PCH стандартных заголовков. Оптимизация, статические CRT/MFC и shader flags
сохранены. Генератор шейдеров x64 использует все логические процессоры.
Чужие процессы не останавливаются; повторной последовательной сборки нет.

Кэш по умолчанию: `builds/rebuild64/cache` относительно корня проекта.
Параметры: `-CacheRoot <путь> -CacheLimitGB 20 -CacheVersions 2`.
Кэш содержит LuaJIT (библиотека, заголовки, jit), DirectXTex/TK (LIB/PDB),
ресурсы RendererShaders и объекты Recast/Detour с исходными флагами Game.
Отдельные ключи учитывают исходники каждой библиотеки и общие рецепты сборки,
версии и бинарные файлы компилятора/линкера/SDK/D3DCompiler, заголовки SDK/MSVC.
Изменение настроек сборки аннулирует все группы; изменение кода игры вне рендера не аннулирует сторонние библиотеки.
Каждый payload проверяется по SHA256SUMS до восстановления; неполные и
повреждённые записи не используются. Публикация, чтение и удаление защищены
эксклюзивной файловой блокировкой на весь запуск. Одновременный запуск с тем же
кэшем завершается ошибкой блокировки: повторите его после окончания первого.
При каждой сборке удаляются старые версии (по последнему использованию), затем
самые старые записи до ограничения объёма. Ссылки и неизвестные каталоги запрещены.
Кэш можно удалить отдельно; он не включается в kit.

Результат в каталоге задания: `kit` (две EXE, два PDB, пять FFmpeg DLL,
release nvngx_dlss.dll, SHA256SUMS), `build.log`, таблицы `*.dependents.txt`
и `build-result.txt` со временем всего запуска, числом MSBuild workers,
ключом, попаданиями и размером кэша. dumpbin проверяет все EXE/DLL комплекта
на отсутствие динамического VC++ runtime. Имеющийся kit сохраняется:
для повторного разрешённого замера перенесите его в другой каталог задания,
а для полной сборки используйте свежую рабочую копию без out.

Замер холодного и тёплого кэша проводят только при разрешении задания/владельца;
не очищайте общий кэш других заданий ради замера. На чистом кэше Hits пуст;
на тёплом — все пять групп. Сравнивают состав SHA256SUMS обоих комплектов,
а поведение с main подтверждают отдельно разрешённым игровым прогоном.
Скрипт игру не запускает, не устанавливает комплект, не вызывает accept,
merge или push. В X64BUILDFAST оба замера разрешены дополнением BRIEF.
