# Встроенный рендер

`external/owned-renderer` — обычный каталог исходников в репозитории EIRebuild.
Он содержит принятую интеграционную редакцию, описанную в его `PROVENANCE.md`.
Submodule и доступ к локальным Git-коммитам разработчика не нужны.

`OwnedRenderer.vcxproj` собирает статическую библиотеку. `RendererShaders.vcxproj`
собирает инструмент генерации ресурсов, компилирует шейдеры и camp art.
EIRebuild линкует библиотеку и ресурсы внутрь EXE. Конфигурация: Release Win32,
v143; в solution выбирается Release/x86. Входная команда — `py -3 build-local.py`
из корня репозитория.

`Renderer.props` задаёт относительный путь к исходникам. Исторический commit
в `EID3D11_BUILD_COMMIT` обозначает происхождение включённой редакции;
точное последующее состояние исходников задаёт commit всего EIRebuild.
Сборка не требует `.git` и не запрещает редактировать рендер.

Исходники рендера, его ресурсы и адаптер `Game/OwnedRender` обновляются одним
согласованным коммитом EIRebuild. При переносе следующей upstream-версии
сохраняйте необходимые изменения адаптера и фиксируйте новую базу в provenance.
