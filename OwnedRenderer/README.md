# Встроенный рендер

`external/owned-renderer` — обычный каталог исходников в репозитории EIRebuild.
Он содержит принятую интеграционную редакцию, описанную в его `PROVENANCE.md`.
Submodule и доступ к локальным Git-коммитам разработчика не нужны.

`OwnedRenderer.vcxproj` собирает статическую библиотеку. `RendererShaders.vcxproj`
собирает инструмент генерации ресурсов, компилирует шейдеры и camp art.
EIRebuild64 линкует код рендера статически. Игра и NavBake используют общую
ресурсную EI.RenderResources.dll рядом с исполняемым файлом. Конфигурация: Release x64,
v143. Входная команда задания — `tools/build-task.ps1`; она готовит локальные
зависимости, компилирует DXBC/DXIL и формирует проверяемый комплект.

Текущая база автора: release/20261123-212c831, `212c831d5129e1425ec622fa7bdb482e37097d84`.
Астрал и растительность используют алгоритмы этой версии. Адаптеры x64,
PAK, glTF/SKN и MCP остаются частью EIRebuild64. Материалы и hosted plants
берутся из content/renderer-materials/Engine64 и content/renderer-assets/Engine64.
Для проверки ещё не принятого content сборка принимает явные
`-RendererMaterialsSource` и `-RendererAssetsSource`.

`Renderer.props` задаёт относительный путь к исходникам. Исторический commit
в `EID3D11_BUILD_COMMIT` обозначает происхождение включённой редакции;
точное последующее состояние исходников задаёт commit всего EIRebuild.
Сборка не требует `.git` и не запрещает редактировать рендер.

Исходники рендера, его ресурсы и адаптер `Game/OwnedRender` обновляются одним
согласованным коммитом EIRebuild. При переносе следующей upstream-версии
сохраняйте необходимые изменения адаптера и фиксируйте новую базу в provenance.

`Game/OwnedRender/ei_renderer_api.h` сохраняет используемые адаптером типы
старого source-host контракта из локальной интеграции c40, commit
`dd7796115027a2e6f67ac5c275581cdbfb4a28a4` (Include/ei_renderer_api.h).
Заголовок перенесён без изменения байтов; отдельная DLL c40 не подключается.
